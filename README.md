honest-out-of-office writes one line to a text file: an out-of-office auto-reply that tells the truth about being away — the polite version first, then the honest version. The line was picked from 36 candidates by pairwise judging against the brief: honesty first, then politeness, then the turn of phrase. The reply performs the honesty it claims: it states the polite reason for being away, then admits what the sender would otherwise only say privately.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 134 characters, a single sentence, and ends on its strongest beat. The program builds the line from two clauses — the polite version, then the honest version — and checks the result against the entry gate (length, single line, single sentence, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
